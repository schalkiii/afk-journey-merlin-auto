# 模板采集规范

本项目的所有界面识别都依赖 `templates/*.png` 的 OpenCV 模板匹配（**无 OCR**）。
一条模板采错，对应功能就会静默失效，且不会报错、只会表现为"界面识别不到 / 连续多轮无变化"。
本文是采集与标定的唯一规范。

## 1. 分辨率

- **一律在 1600×900 客户区采集**（`GetClientRect` 得到的游戏窗口客户区）。
- 游戏 UI **不随窗口等比缩放**：换了窗口尺寸，整套模板与像素偏移会同时失效。
  历史事故：首批愿望单模板在 1302×1080 下采集，换到 1600×900 后「已点击入口 → 未进入界面」，
  14 张模板与全部偏移量重做。
- 改分辨率时，同一功能的**模板 + 相关偏移常量**必须一起重做。

## 2. 裁切

- **避开角标**：左上角档位角标、右上角「完成 / 新」角标会随状态出现或消失。
  愿望单入口模板曾把角标连背景一起裁进去，角标消失即失配。
- **避开动画**：带流光 / 呼吸效果的标题不能直接当唯一判据。实测「完成愿望单」标题
  同一模板连续帧匹配分在 **0.82–0.95** 之间抖动，0.8 阈值会随机漏判。
  这类目标要另找一个静态锚点，或加「其余状态都已排除」的兜底判定。
- **裁到控件主体**：别把大片背景裁进去。背景随季节 / 场景变化时必然失配。
- **必须有纹理**：纯色块的模板在 `TM_CCOEFF_NORMED` 下不可用——归一化会去掉均值，
  纯色模板与任意纯色区域的相关系数都接近 1，会在完全无关的界面上"命中"。
- **角标不能当"通用可领取探测器"**：同一枚橙色礼包角标会按界面缩放（卡片/页签上约 19px，
  奖励行上约 22px），HUD 上的还带脉动缩放动画。实测同一 19px 模板在「目标 / 当前进度 /
  玩法目录」三处只有 **1.0 / 0.709 / 0.469**；只裁中心字形又分不开「礼包」与「!」提醒角标
  （互相 0.95+）；改用 HSV 圆形色块检测又会命中卡面上的橙色徽章。
  结论：角标模板只在**同一面板内**用（实测面板内 1.0），跨界面找角标、以及"有角标就点"都不成立。
- **半透明药丸标签不能做入口判据**：HUD 上的「赛季手册」这类文字标签压在实时场景上，
  镜头换背景后同一模板从 1.0 掉到 **0.767**。改用同处**不透明的图标本体**
  （带流光动画仍稳定 0.965），或干脆按客户区固定点位点击、用"上级界面元素是否消失"校验。
- **区分性优先**：模板要能把它与最容易混淆的界面分开。采完必须验证（见第 4 节）。

## 3. 命名

- 格式：`玩法名 + 控件拼音`，全小写、无分隔符。例：`jieshesaodang`（结社战线-扫荡）、
  `xinyuandanbuzu`（愿望单-不足）、`kaishipengren`（开始烹饪）。
- 状态类模板加状态后缀：`...active`（已激活）/ `...max`（最大档）/ `...wancheng`（完成）。
- 英雄模板例外：由 `warehouse.py` / `hero_metadata.py` 按英雄 ID 动态拼名。

## 4. 阈值与验证

- 默认阈值 `0.8`；对易混淆目标可上调（如页签已激活/未激活互斥用 `0.95`）。
- 采完必须做三项实测，结果记入提交说明：
  1. **目标界面**匹配分（应 ≥0.95，且连续多帧稳定）；
  2. **最易混淆界面**上的最高分（应 ≤0.7；与阈值之间至少留 0.1 余量）；
  3. 若控件可点击，实点一次确认落点正确——**裁错位置也能拿到 1.000 的自匹配分**，
     本轮就发生过「开始烹饪」模板裁到旁边飘带、点击一直落空的事故。
- 反之：**不要只凭"模板能匹配到自己"就认为采对了。**

## 5. 结构相关约定

- 存储位置：源码直接读 `templates/`；打包后由 `common.ensure_appdata_templates()`
  复制到 `%APPDATA%/gamebot/templates`，统一经 `common.get_template_path()` 取路径。
  **不要**自己拼 `get_resource_path("templates")`（`start.py` 曾因此绕过 APPDATA 副本）。
- 位置关系用常量表达，集中写在对应任务模块顶部并注明对应两点的实测屏幕坐标，
  例：`QTY_BUTTON_OFFSET = (110, -10)  # 烹饪 2896,859 / 数量 3006,849`。
- 不是所有"红点 / 新角标"都代表可领取奖励：实测红点可能是**剧情对话**、
  「新」是**内容未读标记**。新增领取流程前先点开确认，别照着角标形状硬做。
- **同一类控件在不同面板可能用不同素材**，不能假定一张模板通吃：左下角返回箭头实测
  任务面板 / 赛季手册 / 玩法目录列表用 `exitck`（0.991，此处 `exit`/`fanhui` 只有 0.42），
  而活动与公会卡片详情页用 `fanhui`/`exit`（`exitck` 只有 0.283）。返回动作要按**候选列表**
  依次尝试（见 `hongbaolingqu._click_panel_back`）。
- **面板会记住上次停留的子页签**，而页签选中态往往换一套外观（变绿 / 加高亮边框），
  拿单个页签当"已进入面板"锚点会误判成没进去并反复重点入口。实测 `fanfanle.png`
  在翻翻乐被选中时只剩 0.724。两种可靠写法：对**多个未选中态**页签做或判断，
  或改用"上级 HUD 元素是否消失"判定进入，并在进入后**显式点回**要扫的那个页签。
